# ecash

Фронтенд сервиса обмена валют: лендинг франшизы, приложение с курсами
и калькулятором, отделения на карте, бронирование и личный кабинет.
Свёрстан по макету Figma, мультиязычный (ru / en / kk), тёмная и светлая темы.

## Стек

- **Next.js 16** (App Router, Turbopack) + **React 19** + TypeScript
- **Tailwind CSS v4** — токены из макета в `src/app/tokens.css`
- **next-intl** — локали ru / en / kk, `/` без префикса, `/en`, `/kk`
- **Framer Motion** — анимации, все уважают `prefers-reduced-motion`
- **Мок-бэкенд** на route handlers, без внешних API

## Структура

```
src/
  app/[locale]/          страницы: лендинг, приложение, кабинет, флоу
  app/api/               мок-бэкенд (rates, branches, auth, bookings, …)
  server/                хранилище в памяти, сессии, хелперы ответов
  lib/                   типизированный клиент API, хуки, доменные типы
  components/
    landing/             лендинг франшизы и его эффекты
    sections/            блоки приложения
    profile/             личный кабинет
    flows/               бронирование, индивидуальный курс, подписка
    ui/                  атомы дизайн-системы
  i18n/                  маршрутизация локалей
messages/                тексты ru / en / kk
design/                  карта экранов макета и инвентарь
scripts/                 выгрузка макета из Figma и извлечение спек
```

## Точка входа

`/` отдаёт разное в зависимости от сессии: гость видит лендинг,
авторизованный — приложение. Решение принимается на сервере по httpOnly-куке,
поэтому нет ни редиректа, ни мигания. Кабинет закрыт серверным layout.

## Работа с макетом

Скрипты в `scripts/` тянут дерево макета через Figma REST API и извлекают
точные спеки: геометрия, автолэйауты, заливки с прозрачностью, типографика.

```bash
npm run figma:structure          # инвентарь страниц и фреймов
npm run spec -- --screens        # карта всех экранов
npm run spec -- 1279:104497      # спека узла
npm run spec -- <id> --text      # только тексты со стилями
```

Нужен `.env.local` (в репозиторий не попадает):

```
FIGMA_TOKEN=<personal access token, scope file_content:read>
FIGMA_FILE_KEY=<ключ файла>
```

Выгруженные дампы и ассеты (`design/raw`, `design/assets`, `design/screens`)
тоже вне репозитория — они весят сотни мегабайт и восстанавливаются скриптами.
